## Условие задачи

### Задание 4. Выпуклые многоугольники

Реализовать класс выпуклых многоугольников на плоскости со следующими возможностями:

- Проверка выпуклости при создании многоугольника по списку вершин.
- Вычисление площади и периметра.
- Проверка принадлежности точки и вложенности одного многоугольника в другой.
- Нахождение пересечения двух многоугольников.
- Триангуляция многоугольника.

---

## Описание решения

В файле `convex_polygons.py` реализован класс `ConvexPolygon`.
Вершины задаются списком пар координат `(x, y)` в порядке обхода границы —
по часовой стрелке или против неё.

| Метод | Назначение |
| --- | --- |
| `area()` | Вычисляет площадь многоугольника. |
| `perimeter()` | Вычисляет периметр многоугольника. |
| `contains(other)` | Проверяет принадлежность точки или вложенность другого многоугольника; граница считается частью многоугольника. |
| `intersection(other)` | Возвращает многоугольник пересечения или `None`, если общей области положительной площади нет. |
| `triangulate()` | Возвращает список из `n - 2` треугольников, где `n` — число вершин. |

При создании проверяются формат координат и выпуклость. Самопересекающиеся
многоугольники и три соседние вершины на одной прямой не допускаются.
Некорректные данные вызывают `ValueError`.

В конце файла приведены примеры для проверки всех операций, отклонения
некорректных данных и запрета присваивания свойству `vertices`.

## Запуск программы

Требуется Python **3.9 или новее**. Виртуальное окружение и дополнительные
пакеты не нужны.

### 1. Клонируйте репозиторий и перейдите в папку задания

Скопируйте и выполните команды в терминале:

```bash
git clone https://github.com/cinq-sur-cinq/task-4-convex-polygons.git
cd task-4-convex-polygons
```

### 2. Запустите программу

macOS/Linux:

```bash
python3 convex_polygons.py
```

Windows:

```powershell
python convex_polygons.py
```

Программа автоматически выполнит примеры и выведет результаты:

- Площадь и периметр квадрата со стороной `4`: оба значения равны `16.0`.
- Проверки принадлежности точек и вложенности многоугольников: `True` или `False`.
- Триангуляция квадрата: два треугольника.
- Пересечение двух перекрывающихся квадратов: многоугольник площадью `4.0`.
- Пересечение непересекающихся многоугольников: `None`.

Сообщения `Rejected: ...` и `vertices is read-only` в конце вывода —
ожидаемые результаты проверок некорректных данных и запрета присваивания
свойству `vertices`.
